Guide de compatibilitéV1.0

Certains constructeurs Android appliquent des politiques d'optimisation batterie très agressives qui peuvent affecter le fonctionnement de RunCrew : notifications retardées, GPS coupé, application fermée en arrière-plan.

Ce guide vous explique comment configurer votre téléphone pour améliorer la fiabilité de RunCrew.

Constructeurs concernés : Huawei, Honor, Xiaomi, Redmi, Poco, OnePlus, Oppo, Vivo, Realme, Meizu.

⚠️ Avertissement légal

Ce guide est fourni à titre informatif. Les procédures peuvent varier selon les versions Android et les mises à jour constructeurs.

RunCrew ne peut pas garantir à 100% la fiabilité des alertes SOS sur les appareils à politique batterie restrictive, même après application de ces réglages.

En cas d'urgence vitale, composez toujours les numéros officiels : 15, 18, 112, 911.

1. Pourquoi ce guide ?

Certains constructeurs Android modifient le comportement standard d'Android pour économiser la batterie. Ces modifications peuvent :

  • Retarder ou empêcher la réception des notifications RunCrew (y compris les alertes SOS)
  • Couper le suivi GPS pendant vos sessions
  • Fermer l'application en arrière-plan
  • Bloquer le démarrage automatique de RunCrew

Ces limitations sont indépendantes de RunCrew. Elles résultent des choix techniques des fabricants d'appareils. Les réglages ci-dessous permettent de rétablir le fonctionnement normal.

2. 🇨🇳 Huawei / Honor

Configuration recommandée

Étape 1 — Désactiver l'optimisation batterie

Paramètres → Batterie → Optimisation de l'application

→ Rechercher RunCrew

→ Sélectionner « Ne pas optimiser »

Étape 2 — Ajouter aux applications protégées

Paramètres → Batterie → Démarrage d'applications

→ Rechercher RunCrew

→ Désactiver « Gérer automatiquement »

→ Activer : ✅ Démarrage automatique

→ Activer : ✅ Démarrage secondaire

→ Activer : ✅ Exécution en arrière-plan

Étape 3 — Verrouiller en mémoire

→ Ouvrir la vue « Applications récentes »

→ Tirer RunCrew vers le bas

→ Cadenas apparaît (verrouillé en mémoire)

Étape 4 — Autoriser les notifications

Paramètres → Notifications → RunCrew

→ Activer TOUTES les catégories

→ Priorité : Élevée

→ Activer pour RunCrew

→ Ouvrir la vue « Applications récentes »

→ Tirer RunCrew vers le bas

→ Icône cadenas apparaît

→ Autoriser les notifications

→ Afficher sur écran verrouillé : activer

Paramètres → Batterie → Économie de batterie → RunCrew

→ Aucune restriction

8. 🔍 Vérification rapide

Après avoir appliqué les réglages pour votre constructeur, effectuez les tests suivants :

Test 1 — Notifications

  1. Fermez complètement RunCrew (swipe up)
  2. Attendez 5 minutes
  3. Demandez à un ami de vous envoyer un message via son crew
  4. La notification doit arriver dans les 30 secondes

Test 2 — SOS

  1. Fermez complètement RunCrew
  2. Rouvrez et lancez une session test
  3. Activez le SOS (test)
  4. Vérifiez que vos supporters reçoivent l'alerte

Test 3 — GPS en arrière-plan

  1. Lancez une session RunCrew
  2. Verrouillez votre téléphone
  3. Marchez pendant 5 minutes
  4. Le tracé doit être continu (pas de trou)

Si les 3 tests sont réussis, votre téléphone est correctement configuré pour RunCrew ! ✅

9. ❌ Si ça ne fonctionne toujours pas

Si malgré ces réglages RunCrew reste peu fiable :

  • Redémarrez votre téléphone après configuration
  • Vérifiez que Android est à jour
  • Vérifiez que RunCrew est à jour sur Google Play
  • Contactez notre support : runcrew.app@gmail.com

10. 🚨 Rappel de sécurité essentiel

Même après configuration parfaite, RunCrew ne peut jamais garantir à 100% la réception des notifications sur les téléphones à politique batterie restrictive.

En cas d'urgence vitale, composez toujours :

📞 15 — SAMU

📞 18 — Pompiers

📞 112 — Numéro européen d'urgence

📞 911 — USA / Canada

Ne vous reposez JAMAIS uniquement sur la fonction SOS de RunCrew.
